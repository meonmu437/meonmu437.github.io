# 잡담 글 작성

평소에는 [GitHub Discussions](https://github.com/meonmu437/meonmu437.github.io/discussions)에서 글을 작성·수정하세요. 게시판의 `+ 알림 붙이기`도 Discussions 작성 화면으로 연결됩니다.

소유자 `meonmu437`가 작성한 글을 새로 게시하거나, 제목·본문·카테고리를 수정하면 GitHub Actions가 `content/posts/`에 마크다운 파일로 자동 저장하고 사이트를 배포합니다. 방문자는 이 파일에서 생성된 게시판을 읽으므로 GitHub API 조회 한도를 사용하지 않습니다. 추가 토큰이나 외부 DB 설정은 필요 없습니다.

- Discussion 글 번호와 기존 `post.html?id=번호` 주소는 유지됩니다.
- 다른 사용자가 작성한 Discussion과 댓글은 가져오지 않습니다.
- 연결된 마크다운 파일의 제목·본문·카테고리·날짜는 동기화 때 Discussions 내용으로 덮어씁니다. 해당 글은 Discussions에서 수정하세요.
- 마크다운의 `pinned`와 `draft` 설정은 동기화 후에도 유지합니다.
- Discussion 삭제는 파일을 자동으로 지우지 않습니다. 게시판에서 감추려면 해당 파일에 `draft: true`를 넣으세요.
- 이벤트가 몰려도 누락되지 않도록 실행할 때마다 소유자의 전체 Discussion을 확인합니다. 같은 내용은 다시 커밋하지 않습니다.
- 자동 저장 커밋은 별도 배포 실행을 시작하지 않으므로 같은 워크플로 안에서 빌드·배포합니다.

파일로 직접 글을 추가할 수도 있습니다. `content/TEMPLATE.md`를 복사해 `.md` 파일을 만들되, Discussion과 번호가 겹치지 않게 하세요. 충돌하면 자동 동기화는 덮어쓰지 않고 오류로 중지합니다.

- `id`: 중복 없는 양의 정수. 현재 마지막 번호는 62이므로 다음 글은 63입니다. 발행 후 바꾸지 마세요. 기존 주소와 댓글이 이 번호를 사용합니다.
- `title`, `date`: 제목과 작성 날짜. 날짜는 `2026-11-08T15:00:00+09:00`처럼 적습니다.
- `category`: 카테고리 이름. 기존 카테고리 이름을 그대로 쓰거나 새 이름을 쓰면 탭이 자동으로 생깁니다.
- `emoji`: 카테고리 이모지. `pinned: true`는 고정 글, `draft: true`는 비공개 초안입니다.
- `categorySlug`, `updated`, `originalUrl`: 이전 글에서 옮겨온 보조 정보이며 새 글에서는 생략해도 됩니다.

마크다운과 HTML(표, 접기, 이미지, 일부 인라인 스타일)을 섞을 수 있습니다. 스크립트, 이벤트 속성, 위험한 URL과 스타일은 빌드 중 제거됩니다. 기존 GitHub 첨부 이미지는 기존 주소를 유지하며, 새 이미지는 `images/`에 올려 `/jamdam/images/파일명.webp`로 삽입할 수 있습니다.

커밋하면 기존 GitHub Pages 워크플로가 자동으로 빌드합니다. 로컬 빌드는 `npm ci` 후 `npm run build`로 실행하고 `dist/`를 정적 서버로 확인합니다. 방문자는 생성된 JSON과 HTML만 읽고 GitHub API를 호출하지 않습니다.

댓글 기능과 이전 GitHub 댓글 링크는 표시하지 않습니다. 기존 익명 이모지 반응 카운터는 유지했습니다.
